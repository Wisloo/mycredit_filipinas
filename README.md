## What is MyCredit Filipinas?

MyCredit Filipinas is a loan management system designed to streamline the borrowing process. Borrowers can apply for loans, track their payments, and manage their accounts — all in one place. On the other side, administrators can review applications, verify payments, and manage the entire lending workflow from a single dashboard.

## Key Features

- Online loan application (₱5K – ₱30K)
- Multiple payment methods (Cash, GCash, Bank Transfer, Maya, Check)
- Real-time loan and payment tracking
- Admin dashboard for loan approval and user management
